Notifikasi "ruang penyimpanan hampir penuh" muncul, padahal rasanya kamu tidak menyimpan banyak file. Update Windows gagal, aplikasi lambat, dan laptop terasa makin berat. Storage yang penuh bukan cuma soal tidak ada ruang: kondisi ini ikut memengaruhi kelancaran Windows.

## Jawaban Singkat

Biasanya storage penuh karena **penumpukan hal-hal yang jarang dilihat**: file unduhan, foto dan video, cache aplikasi, file sementara, dan berkas sistem seperti update Windows. Cara paling aman memulainya adalah **melihat dulu apa yang memakai ruang** lewat menu Penyimpanan bawaan Windows, bukan langsung menghapus file secara acak.

## Penyebab Umum

| Penyebab | Kenapa bisa besar | Tindakan yang relatif aman |
|---|---|---|
| Foto dan video | Satu video bisa memakan ratusan MB sampai GB | Pindahkan ke hard disk eksternal atau cloud |
| Folder Unduhan | Installer dan file lama menumpuk tanpa disadari | Cek dan hapus yang sudah tidak dipakai |
| Aplikasi dan game | Ukurannya makin besar dari waktu ke waktu | Uninstall yang sudah tidak dipakai |
| File sementara dan cache | Menumpuk dari browser dan aplikasi | Bersihkan lewat fitur bawaan Windows |
| Update dan berkas sistem Windows | Update besar meninggalkan file pendukung | Jangan hapus manual; gunakan pembersihan bawaan |
| Media chat dan file kiriman | Foto dan video dari chat tersimpan otomatis | Cek folder media aplikasi chat |
| File duplikat | Salinan yang sama tersebar di banyak folder | Cek dan hapus yang benar-benar dobel |

## Cara Mengeceknya

Di Windows 10 dan 11, buka **Pengaturan → Sistem → Penyimpanan**. Di sana terlihat kategori apa yang paling banyak memakan ruang, seperti Aplikasi, Sementara, atau Dokumen. Mulailah dari kategori terbesar. Windows juga menyediakan fitur pembersihan bawaan (seperti Storage Sense atau Pembersihan Disk) yang lebih aman daripada menghapus file sistem sendiri.

**Jangan menghapus folder sistem seperti Windows atau Program Files.** Menghapus sembarang file di sana bisa membuat Windows atau aplikasi berhenti bekerja.

## Kenapa Storage Penuh Bikin Laptop Terasa Lemot?

Windows membutuhkan ruang kosong untuk file sementara dan update. Banyak panduan menyarankan menyisakan ruang kosong yang lumayan, jangan diisi sampai penuh. Pada drive yang hampir penuh, kinerja bisa menurun dan update Windows lebih mungkin gagal. Pada laptop lama, ini sering memperparah rasa lemot yang sudah ada karena hard disk.

## Kalau Sudah Dibersihkan tapi Masih Penuh

Kalau setelah dibersihkan storage tetap penuh, pertimbangkan dua jalur:

1. **Pindahkan data besar ke penyimpanan lain.** Foto, video, dan arsip kerja lebih cocok disimpan di hard disk eksternal. Baca [apa yang perlu dibackup dan di mana](/tips/backup-data-penting-laptop-hp).
2. **Tambah atau ganti kapasitas storage di dalam laptop.** Cek dulu tipe storage yang dipakai laptopmu, lalu lihat [SSD 256GB vs 512GB untuk laptop lama](/tips/ssd-256gb-vs-512gb-laptop-lama) dan [SSD atau HDD untuk laptop lama](/tips/ssd-atau-hdd-laptop-lama).

## Kapan Sebaiknya Dibawa ke Teknisi

- Drive C: cepat penuh lagi tanpa alasan yang jelas, padahal kamu tidak menambah file besar.
- Update Windows berulang kali gagal karena ruang tidak cukup.
- Muncul peringatan kesehatan drive, atau laptop sering hang dengan penggunaan disk yang terus tinggi.
- Kamu ingin mengganti storage dan memindahkan data lama tanpa install ulang.

Sebelum apa pun dilakukan, pastikan file penting sudah dicadangkan.
