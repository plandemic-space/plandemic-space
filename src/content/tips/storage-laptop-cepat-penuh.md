Notifikasi "ruang penyimpanan hampir penuh" muncul, padahal rasanya kamu nggak nyimpen banyak file. Update Windows gagal, aplikasi lambat, dan laptopnya kerasa makin berat. Storage yang penuh bukan cuma soal kehabisan ruang: kondisi ini ikut ngaruh ke kelancaran Windows-nya juga.

## Jawaban Singkat

Biasanya storage penuh gara-gara **numpuknya hal-hal yang jarang diliat**: file unduhan, foto dan video, cache aplikasi, file sementara, dan berkas sistem kayak update Windows. Cara paling aman mulainya adalah **liat dulu apa yang makan ruang** lewat menu Penyimpanan bawaan Windows, bukan langsung ngehapus file sembarangan.

## Penyebab Umum

| Penyebab | Kenapa bisa gede | Tindakan yang relatif aman |
|---|---|---|
| Foto dan video | Satu video aja bisa makan ratusan MB sampai GB | Pindahin ke hard disk eksternal atau cloud |
| Folder Unduhan | Installer dan file lama numpuk tanpa disadari | Cek dan hapus yang udah nggak dipakai |
| Aplikasi dan game | Ukurannya makin gede dari waktu ke waktu | Uninstall yang udah nggak dipakai |
| File sementara dan cache | Numpuk dari browser dan aplikasi | Bersihin lewat fitur bawaan Windows |
| Update dan berkas sistem Windows | Update gede ninggalin file pendukung | Jangan hapus manual; pakai pembersihan bawaan |
| Media chat dan file kiriman | Foto dan video dari chat kesimpen otomatis | Cek folder media aplikasi chat |
| File duplikat | Salinan yang sama nyebar di banyak folder | Cek dan hapus yang beneran dobel |

## Cara Ngeceknya

Di Windows 10 dan 11, buka **Pengaturan → Sistem → Penyimpanan**. Di situ keliatan kategori apa yang paling banyak makan ruang, kayak Aplikasi, Sementara, atau Dokumen. Mulai dari kategori yang paling gede. Windows juga nyediain fitur pembersihan bawaan (kayak Storage Sense atau Pembersihan Disk) yang lebih aman daripada ngehapus file sistem sendiri.

**Jangan hapus folder sistem kayak Windows atau Program Files.** Ngehapus sembarang file di situ bisa bikin Windows atau aplikasi berhenti jalan.

## Kenapa Storage Penuh Bikin Laptop Kerasa Lemot?

Windows butuh ruang kosong buat file sementara dan update. Banyak panduan nyaranin nyisain ruang kosong yang lumayan, jangan diisi sampai penuh. Di drive yang hampir penuh, kinerjanya bisa menurun dan update Windows lebih gampang gagal. Di laptop lama, ini sering nambah parah rasa lemot yang udah ada gara-gara hard disk.

## Kalau Udah Dibersihin tapi Masih Penuh

Kalau udah dibersihin tapi storage-nya tetap penuh, pertimbangin dua jalur:

1. **Pindahin data besar ke penyimpanan lain.** Foto, video, dan arsip kerja lebih cocok disimpen di hard disk eksternal. Baca [apa yang perlu dibackup dan di mana](/tips/backup-data-penting-laptop-hp).
2. **Tambah atau ganti kapasitas storage di dalam laptop.** Cek dulu tipe storage yang dipakai laptopmu, terus lihat [SSD 256GB vs 512GB untuk laptop lama](/tips/ssd-256gb-vs-512gb-laptop-lama) dan [SSD atau HDD untuk laptop lama](/tips/ssd-atau-hdd-laptop-lama).

## Kapan Sebaiknya Dibawa ke Teknisi

- Drive C: cepat penuh lagi tanpa alasan yang jelas, padahal kamu nggak nambah file besar.
- Update Windows berulang kali gagal gara-gara ruangnya nggak cukup.
- Muncul peringatan kesehatan drive, atau laptopnya sering hang dengan pemakaian disk yang terus tinggi.
- Kamu mau ganti storage dan pindahin data lama tanpa install ulang.
